## 1. 1 回目の 8 案の組み立て方

まず「配置 × 書体 × 色」の組み合わせが 8 案で重ならないように表を作り、それから HTML を書く。表を先に作ると、書いているうちに似た案に寄っていくのを防げる。

| # | 配置 | 書体 | 色 | 見出しの切り口 |
| --- | --- | --- | --- | --- |
| 1 | 写真全面＋下帯 | 明朝 | 白帯・黒文字 | 季節 |
| 2 | 文字だけ・特大 | 極太ゴシック | ブランド色背景 | 効果 |
| 3 | 左右分割 | 丸ゴシック | 淡い背景 | 人 |
| … | | | | |

8 案のうち 1〜2 案は、ユーザーが想像していなさそうな案（暗い背景、縦書き、余白を大きく取る、など）にする。選ばれなくても「これは違う」がわかれば、次の回の手がかりになる。

## 2. 配置のパターン

- **写真全面＋帯**: 写真を背景にし、上か下に帯を置いて文字を載せる。写真を生かしつつ文字が読める。
- **文字だけ・特大**: 見出しを画面の 6〜8 割の大きさにする。縮小表示でも強い。
- **左右（上下）分割**: 片方に写真、片方に文字。情報を整理して見せやすい。
- **枠・余白**: 写真を小さめの枠に入れ、周りに余白を取る。上品・落ち着いた印象。
- **斜め・重ね**: 帯や写真を傾ける、文字を写真に重ねる。動きが出る。
- **縦書き**: `writing-mode: vertical-rl`。和の雰囲気。数字は `text-combine-upright: all` で縦中横にする。
- **大きな数字**: 価格・日付・割合を主役にする。数字はユーザーから受け取ったものだけ。
- **カード・リスト**: 項目を 3〜4 個並べる。図解や「ポイント 3 つ」向き。

## 3. 日本語で使える Google Fonts

`<link href="https://fonts.googleapis.com/css2?family=Zen+Maru+Gothic:wght@500;900&display=block" rel="stylesheet">` のように読み込む。複数を読むときは `family=` を `&` でつなぐ。

| 印象 | フォント名（family） |
| --- | --- |
| 標準・読みやすい | Noto Sans JP, M PLUS 1p, BIZ UDPGothic |
| 力強い・目立つ | Dela Gothic One, Mochiy Pop One, RocknRoll One |
| やわらかい・親しみ | Zen Maru Gothic, M PLUS Rounded 1c, Kosugi Maru |
| 上品・伝統 | Noto Serif JP, Shippori Mincho, Zen Old Mincho |
| 手書き風・素朴 | Klee One, Yomogi, Zen Kurenaido |
| かわいい・ポップ | Hachi Maru Pop, Kaisei Decol |

`render.mjs` が `font-not-loaded` を出したら、フォント名の綴りと `wght` の指定（そのフォントにない太さを指定していないか）を確かめる。

## 4. 日本語の文字組み

- **改行は自分で決める。** 見出しは意味の切れ目で `<br>` を入れる。長い本文は `word-break: auto-phrase` で文節の途中で改行されにくくなる（`<html lang="ja">` がないと効かない）。
- **行間**: 見出しは `line-height: 1.2〜1.35`、本文は `1.6〜1.8`。
- **字間**: 大きい見出しは `letter-spacing: 0.02〜0.08em` 程度空けると締まる。約物（「」、。）の前後の空きが気になるときは `font-feature-settings: "palt"` を使う。
- **句読点**: 見出しの最後の「。」は、あえて付けない／付けるで印象が変わる。案の違いとして使ってよい。
- **英数字**: 和文フォントの英数字が弱いときは、英字だけ別のフォント（Inter、Montserrat など）を `font-family` の先頭に置く。

## 5. 写真の上に文字を載せる

写真の明るい部分に白文字を載せると読めない。次のどれかで必ず読めるようにする。

- 文字の後ろに半透明の帯を敷く（`background: rgba(0,0,0,.45)`）。
- 写真にグラデーションを重ねる（`linear-gradient(transparent 50%, rgba(0,0,0,.6))`）。
- 文字に影を付ける（`text-shadow: 0 2px 12px rgba(0,0,0,.5)`）。弱い対策なので、上のどちらかと組み合わせる。
- 写真の空いている場所に文字を置く（`object-position` で切り取り位置を変える）。

写真は `object-fit: cover` で枠いっぱいにし、主役（人の顔・商品）が切れないように `object-position` を調整する。

## 6. 色

- 1 枚に使う色は、背景・主・差し色の 3 色程度にする。
- 文字と背景の明るさの差を十分に取る。迷ったら一覧画像の縮小表示で読めるかを見る。
- ブランド色が決まっているときは、それを主にし、残りの案で反対色・モノトーンを試す。
- 季節感: 春（桜色・若草）、夏（青・白）、秋（橙・茶）、冬（白・紺・赤）。
